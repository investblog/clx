Diese Richtlinie gilt für die kostenlosen QR-Code-Tools von clx: den QR-Code-Generator auf dieser Website, die QR-Code-API unter qr.clx.cx und die Browser-Erweiterung (ihre Seite). Keines davon braucht ein Konto, setzt ein Cookie, zeigt Werbung oder betreibt Analyse. Die Richtlinie für clx-Konten steht auf einer eigenen Seite (auf Englisch).

Der Generator auf dieser Website

Der QR-Code wird in Ihrem Browser gezeichnet. Was Sie eingeben, wird nirgendwohin gesendet: Die Seite stellt damit keine Anfrage. Der Bildlink und das angezeigte HTML entstehen ebenfalls im Browser; die API erreichen sie erst, wenn jemand sie öffnet. Der Generator speichert nichts von dem, was Sie eingeben, und setzt kein Cookie; was die Website selbst speichert – das Design, einen Partnercode aus einem Link –, steht auf der Datenschutzseite von clx (auf Englisch).

Die API unter qr.clx.cx

Die API erhält eine Anfrage, wenn ein Link auf sie geöffnet wird – von Ihnen oder vom Browser aller, die eine Seite oder eine E-Mail mit einem solchen Bild ansehen. Die Anfrage enthält den zu codierenden Text, die Größe, die Fehlerkorrektur und den Rand sowie, wie jede Anfrage im Web, die IP-Adresse des Betrachters, seinen Browser (User-Agent) und oft die Seite, von der sie kommt (Referer). Die API:

  • verwendet den Text nur, um das Bild zu zeichnen und den Hash des Links zu prüfen;
  • führt keine Protokolle über Anfragen und speichert kein Bild; nur die Antworten von /qr.inline bleiben 24 Stunden im Cache von Cloudflare, abgelegt unter ihrer vollständigen Adresse, und verfallen dann;
  • zählt niemanden, erstellt keine Profile und verfolgt niemanden.

Ein QR-Code ist nicht geheim: Wer seinen Link hat oder ihn scannt, liest seinen Text. Codieren Sie keine Passwörter oder andere Geheimnisse.

Die Browser-Erweiterung

Ab Version 1.1.0 stellt die Erweiterung überhaupt keine Netzwerkanfragen: Codes und Freigabelinks entstehen im Browser. Versionen vor 1.1.0 schickten den Text jedes erstellten Codes an die API unter ihrer alten Adresse, qr.qrcgen.com. Die Berechtigungen der Erweiterung:

  • Seitenleiste – um ihr Fenster anzuzeigen (Chrome, Edge; Firefox zeigt eine Sidebar ohne Berechtigung);
  • Speicher – um Ihre Optionen (Design, Standardgröße und Standard-Fehlerkorrektur, Verlaufslimit, automatisches Generieren) und den Verlauf der Codes, deren Link Sie kopiert haben, zu speichern, nur in Ihrem Browser;
  • Tabs – um die Adresse der aktuellen Seite zu lesen und daraus den Code zu erstellen.

Nichts, was die Erweiterung speichert, verlässt Ihren Browser oder wird synchronisiert; beim Deinstallieren wird es entfernt.

Wer die Daten verarbeitet

Die API und die Seiten dieser Website laufen bei Cloudflare (Workers), außer den russischen Seiten (ru.clx.cx), die bei GitHub Pages liegen; jeder Anbieter verarbeitet die Anfragen, die er als Host beantwortet, nach seiner eigenen Richtlinie. Wir binden keine Analyse von Cloudflare oder anderen ein; wir sehen nur die Zahlen der Anfragen und Fehler, die Cloudflare jedem Konto anzeigt, ohne deren Inhalt. Es werden keine Daten verkauft oder an andere weitergegeben.

Kinder

Die QR-Code-Tools erheben absichtlich keine personenbezogenen Daten, von niemandem, auch nicht von Kindern, und speichern nichts über den oben beschriebenen 24-Stunden-Cache von /qr.inline hinaus; was eine Anfrage von sich aus enthält, ist ebenfalls dort beschrieben.

Änderungen und Fragen

Wird diese Richtlinie geändert, ändert sich ihr Datum oben. Fragen: über das Kontaktformular, das unten auf jeder Seite verlinkt ist, oder als Issue im Repository der API, github.com/investblog/qr-generator. Missbrauch eines QR-Codes: so melden Sie ihn (auf Englisch).
