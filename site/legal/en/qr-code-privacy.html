Privacy of the QR code tools

Version of 12 November 2026.

This policy covers clx's free QR code tools: the QR code generator on this site, the QR code API at qr.clx.cx and the browser extension (its page). None of them has accounts, cookies, ads or analytics. The policy of clx accounts is another page.

The generator on this site

The QR code is drawn in your browser. What you type is not sent anywhere: the page makes no request with it. The image link and the HTML it shows are built in the browser too; they reach the API only when someone opens them. The generator keeps nothing of what you type and sets no cookie; what the site itself keeps — the theme, a partner's code from a link — is on clx's privacy page.

The API at qr.clx.cx

The API receives a request when a link to it is opened — by you, or by the browser of anyone who views a page or an e-mail that shows such an image. The request carries the text to encode, the size, the error correction and the margin, and, like every request on the web, the viewer's IP address, browser (User-Agent) and often the page it came from (Referer). The API:

  • uses the text only to draw the image and to check the link's hash;
  • keeps no logs of requests and stores no image; only the answers of /qr.inline stay in Cloudflare's cache for 24 hours, keyed by their full address, and then expire;
  • does not count, profile or follow anyone.

A QR code is not a secret: anyone who has its link, or scans it, reads its text. Do not encode passwords or other secrets.

The browser extension

From version 1.1.0 the extension makes no network requests at all: codes and share links are made in the browser. Versions before 1.1.0 sent the text of every code they made to the API at its old address, qr.qrcgen.com. The extension's permissions:

  • side panel — to show its window;
  • storage — to keep your settings (theme, default size and error correction, history limit, auto-generate) and the history of codes whose link you copied, in your browser only;
  • active tab and tabs — to read the address of the current page, to make its code.

Nothing the extension keeps leaves your browser or is synced; uninstalling it removes it.

Who processes the data

The API and this site's English pages run on Cloudflare (Workers), and the Russian pages (ru.clx.cx) on GitHub Pages; each handles the requests it serves as their host, under its own policy. We add no analytics of Cloudflare's or anyone else's; we see only the counts of requests and errors that Cloudflare shows to every account, without their content. No data is sold or shared with anyone else.

Children

The QR code tools collect no personal information on purpose, of anyone, children included, and keep nothing beyond the 24-hour /qr.inline cache described above; what a request carries by itself is described there too.
